The Searched Line

Parse and analyze log files for patterns. A detectorist sweeps a wide field of sand in slow arcs, listening for the few specific things buried in it; this tool sweeps a log file the same way, searching for the pattern it is given and lifting out the addresses, error codes, and agents it is asked for.

What it does

The tool parses a log file and searches it: a regular expression pattern to hunt for, and three extraction switches that pull out and analyze IP addresses, error codes, and User-Agent strings. Usage, as the README gives it: ./analyze-logs [params]. Its one requirement is pandas>=2.1.0.
